# 🔐 Simple Secure Login System

A beginner-friendly **Python + MySQL** project that demonstrates basic cybersecurity practices.

Instead of storing passwords in plain text, this project **hashes** them using `bcrypt` and uses **parameterized queries** to help prevent SQL injection.

---

## ✨ Features

- User registration
- User login
- Passwords are hashed with **bcrypt** (never stored as plain text)
- Safe SQL queries (protects against basic SQL injection)
- Super simple CLI interface

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| **Python 3** | Main language |
| **MySQL** | Database |
| **mysql-connector-python** | Connect Python to MySQL |
| **bcrypt** | Secure password hashing |
